## MiMu Glove — Confirmed Controls

### 🎙️ Voice Effects

| Gesture / Control  | Function                                              |
| ------------------ | ----------------------------------------------------- |
| 💫 **Wrist flick** | **Stutter / freeze grab** — triggers the voice effect |
| ✊ **Fist**         | **Voice effect ON**                                   |
| 🖐️ **Open hand**  | **Normal / dry voice** — bypasses everything          |

### 🎛️ Voice Glove Button

The voice glove uses the same **button / LED / microphone pinout**.

| Button action | Function                         |
| ------------- | -------------------------------- |
| **Hold**      | **Record take**                  |
| **Tap**       | **Cycle through effect presets** |

### ✅ Final Behavior

* **Open hand** → completely dry/normal voice
* **Fist** → voice effects enabled
* **Wrist flick** → triggers **stutter/freeze grab**
* **Button hold** → records a take
* **Button tap** → cycles through voice-effect presets
