Live hand: tilt = pitch, roll = brightness, yaw = pan, index = volume, middle = vibrato. Fist and open hand are sound on and off, point is the next instrument, a wrist flick is a drum hit.
Loop hand: roll = scrub, tilt = loop speed, yaw = its own pan, index = live/loop blend, middle = reverb. Fist freezes, open releases, point cycles normal → granular → slices, a flick fires a slice.
